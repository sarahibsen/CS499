## System Requirements

*   **Operating System:**  Windows 10 or later (64-bit), macOS Monterey (12.0) or later, Ubuntu 20.04 or later 
*   **Python:** **No Python installation is required!** This program includes everything it needs to run.


## Installation and Running Instructions

**Important:** You do **not** need to install Python or any other libraries to run this program.

1.  **Download:**
    *   Go to the [Releases page](https://github.com/sarahibsen/CS499/releases/tag/v1.0.0-alpha).
    *   Download the correct file for your operating system:
        *   **Windows:** Download `[GUI].exe`
        *   **macOS:** Download `[GUI].dmg` or `[GUI].app.zip` (adjust as needed)
        *   **Linux:** Download `[GUI]` (the executable file)

2.  **Run the Program:**

    *   **Windows:**
        *   Find the downloaded `[GUI].exe` file (likely in your 'Downloads' folder).
        *   **Double-click** the `.exe` file to start the program.
        *   **Note:** Windows Defender SmartScreen or other antivirus software might show a warning because the application is not signed.
            *   If you see a "Windows protected your PC" screen, click "**More info**" and then "**Run anyway**".
            *   If your antivirus flags the file, you may need to temporarily disable it or add an exception for the file. *We assure you the file is safe if downloaded from the official link above.*

    *   **macOS:**
        *   *(If downloaded as .dmg):* Double-click the `.dmg` file, then drag the `[GUI].app` icon to your Applications folder. Double-click it from Applications to run.
        *   *(If downloaded as .app or .zip):* Unzip the file if necessary. Double-click the `[GUI].app` file.
        *   **Note:** You might see a warning saying the application is from an unidentified developer.
            *   Right-click (or Control-click) the application icon.
            *   Select "**Open**" from the context menu.
            *   You might see the warning again, but this time there will be an "**Open**" button. Click it. You should only need to do this the first time.

    *   **Linux:**
        *   Open your terminal.
        *   Navigate to the directory where you downloaded the file (e.g., `cd ~/Downloads`).
        *   Make the file executable: `chmod +x ./[GUI]`
        *   Run the program: `./[GUI]`

## How to Use

1.   Launch the application.
2.  Click the 'Load Data' button.
3.  Select your input file.
4.  Choose the desired analysis from the drop down.
5.  Click the export button located right of the table. (Export options: txt, csv, tsv)
